# 30-Second Demo Video Note

Goal: create a short user-facing walkthrough that helps a first-time SE understand how to start with Oracle Architecture Arena.

Recommended flow:

1. Open Competitive SE Assist and enter an incomplete customer signal.
2. Generate the SE Assistant output and show discovery questions, Oracle positioning, and battle-card guidance.
3. Send the saved scenario into Debate Arena and generate the multi-agent recommendation.
4. Open Architecture Generator and generate the saved architecture blueprint from the scenario.
5. End on Scenarios as the use case catalog where the work can be revisited.

Tone: fast, practical, and field-focused. The message should be: start with incomplete customer context, turn it into decision guidance, then carry it into debate and architecture generation.
